## Stack + shape
- Single-package TanStack Start app (React 19 + Vite + Tailwind v4); no monorepo/workspaces.
- File-based routes live in `src/routes`; router wiring is in `src/router.tsx` and `src/routes/__root.tsx`.
- Server logic is in `src/server-functions/index.ts` (Google Places + optional OpenAI reranking).

## Commands that matter
- Install: `npm install`
- Build: `npm run build`
- Test (full): `npm run test`
- Lint (no fix): `npm run lint`
- Format check only: `npm run format`
- Auto-fix formatter+lint: `npm run check` (runs `prettier --write .` then `eslint --fix`)

## Env + secrets
- `npm run dev` is wrapped with 1Password CLI: `op run --env-file .env -- vite dev --port 3000`.
- `.env` is 1Password-generated; manual edits are overwritten.
- Required env vars used by code: `GOOGLE_PLACES_API_KEY`; `OPENAI_API_KEY` enables AI reranking but code falls back if missing.
- Never commit `.env` or API keys (`.env` is gitignored).

## Repo-specific gotchas
- `src/routeTree.gen.ts` is auto-generated by TanStack Router and marked readonly in `.vscode/settings.json`; do not edit manually.
- Search/form state is URL-driven (`Route.useSearch()` + `navigate({ search })`), so changes to form fields must stay in sync with `SearchState` and route search validation in `src/routes/index.tsx`.
- `dateTimeSchema` allows only `Morning | Afternoon | Now | Anytime` (`src/schemas/index.schema.ts`); if UI options change, update schema and related filtering logic together.
- Google Places fetch uses `places:searchText` with a required field mask constant; keep requested fields aligned with downstream type usage.
